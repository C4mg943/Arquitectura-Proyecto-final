El problema

Los pequeños productores agrícolas en Colombia carecen de herramientas digitales accesibles para gestionar sus cultivos, monitorear el clima, recibir alertas y coordinarse con técnicos y operarios. Operan con dispositivos móviles de gama baja y conectividad intermitente.

61 Requisitos Funcionales

  • RF1-RF10: Autenticación y usuarios
  • RF11-RF25: Gestión de fincas, parcelas y cultivos
  • RF26-RF30: Actividades agrícolas
  • RF31-RF40: Recomendaciones y alertas
  • RF41-RF50: Reportes y auditoría
  • RF51-RF61: Notificaciones y offline

7 Atributos de Calidad

  • Disponibilidad: 99% (6am-11pm)
  • Rendimiento: <3s consulta cultivo
  • Usabilidad: registro en 3 pasos en móvil
  • Seguridad: bcrypt + JWT
  • Conectividad: sincronización offline
  • Escalabilidad: 500+ usuarios
  • Interoperabilidad: API meteorológica externa

Restricciones Arquitectónicas

Móviles gama baja → optimización, lazy loading
Conectividad limitada → IndexedDB, PWA
4 Roles → ADMIN, PRODUCTOR, OPERARIO, TÉCNICO
Multi-tenant por finca con validación geográfica
